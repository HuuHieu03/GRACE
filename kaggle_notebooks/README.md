# Kaggle Execution Notebooks & Results

Thư mục này dùng để lưu trữ các tệp Jupyter Notebook (`.ipynb`) đã được tải về từ Kaggle sau khi chạy thực nghiệm thành công.

## Quy tắc đặt tên file notebook kết quả:
- `vX.Y.Z_YYYY-MM-DD_<experiment_name>_results.ipynb`
- Ví dụ:
  - `v1.0.0_2026-08-04_devign_5pct_qwen2.5_results.ipynb`
  - `v1.0.0_2026-08-04_reveal_5pct_qwen2.5_results.ipynb`

## Hướng dẫn lưu file:
1. Khi chạy xong notebook trên Kaggle, vào menu **File** -> **Download Notebook** (tải tệp `.ipynb` đã lưu đầy đủ Cell Outputs & Logs).
2. Di chuyển tệp `.ipynb` đã tải về vào thư mục `kaggle_notebooks/` này.
3. Cập nhật báo cáo kết quả tương ứng trong `project_docs/progress/` hoặc `project_docs/history/`.
