# Kế Hoạch: Trích xuất Đồ thị (Joern) cho Devign và Reveal (Phiên bản v1.0.0)

## 1. Tổng Quan & Mục Tiêu (Overview & Objectives)
- **Bối cảnh (Context)**: Dự án yêu cầu trích xuất thông tin Đồ thị cấu trúc mã (CPG) từ mã nguồn gốc cho 2 dataset là Devign và Reveal. Quá trình này cần chạy trên môi trường Ubuntu bằng Joern, nhưng code lưu trữ tại Windows (hệ thống Dual-boot).
- **Mục tiêu chính (Key Objectives)**:
  - Tải 2 bộ dữ liệu `google/code_x_glue_cc_defect_detection` và `Oscaraandersson/reveal` từ Hugging Face.
  - Tách các hàm C/C++ thành các file `.c` vật lý.
  - Chạy Joern trên Ubuntu bằng cách mount ổ đĩa Windows trực tiếp.
  - Chuyển đổi và gom (merge) dữ liệu JSON của Joern về đúng định dạng gốc của GRACE.
