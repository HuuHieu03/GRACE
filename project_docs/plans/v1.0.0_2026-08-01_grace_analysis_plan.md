# Kế Hoạch Tái Tạo Kết Quả Bài Báo GRACE (v1.0.0)

Tài liệu này tổng hợp các phân tích, đối chiếu giữa bài báo *"GRACE Empowering LLM-based software vulnerability detection with graph structure and in-context learning"* và mã nguồn đính kèm, đồng thời đề xuất kế hoạch chi tiết để tái tạo kết quả thực nghiệm.

---

## 1. Phân Tích Sự Khác Biệt & Khuyết Thiếu Cốt Lõi

Quá trình kiểm tra mã nguồn cho thấy kho lưu trữ hiện tại đang thiếu hụt một số điểm cốt lõi so với bài báo:

### A. Tiền xử lý & Trích xuất đồ thị (Graph Structure - Joern)
* **Lý thuyết bài báo**: Sử dụng công cụ **Joern** để phân tích mã C/C++ (các tập dữ liệu FFmpeg+Qemu, Big-Vul, Reveal) nhằm trích xuất Code Property Graph (CPG) bao gồm AST, PDG và CFG.
* **Mã nguồn thực tế (`util.py`)**: File này chứa mã JavaScript gọi `@solidity-parser/parser` cho Solidity, không áp dụng cho C/C++. Mã trích xuất CPG bằng Joern bị thiếu hoàn toàn. Script `llmpre.py` đang phụ thuộc vào file JSON có sẵn `devign_test_processed.json`.

### B. Module Lựa chọn Ví dụ Mẫu (Demonstration Selection - `genexample.py`)
* **Lý thuyết bài báo**: Dùng **CodeT5** trích xuất đặc trưng ngữ nghĩa, giảm chiều T-SNE và khoảng cách $L_2$. Kết hợp độ tương đồng từ vựng (Jaccard) và cú pháp (SimSBT) để tính điểm hỗn hợp.
* **Mã nguồn thực tế**: File `genexample.py` bị thiếu các module phụ thuộc (`bert_whitening.py`, các file `.pkl`), sử dụng FAISS chỉ mục Inner Product thay vì $L_2$.

### C. Mã nguồn chạy LLM (`basep.py`, `llmpre.py`)
* **Đường dẫn cứng (Hardcoded paths)**: Đang fix cứng theo máy cá nhân tác giả (`F:/pycharmfile/...`).
* **Lắp ráp Prompt**: Cấu trúc prompt trong `llmpre.py` bị đảo vị trí so với Hình 6 trong bài báo.

## 2. Kế Hoạch Triển Khai 4 Giai Đoạn

### Giai đoạn 1: Chuẩn bị dữ liệu và Xây dựng lại Pipeline tiền xử lý với Joern
- [ ] Tải các tập dữ liệu Devign, Reveal, Big-Vul theo hướng dẫn.
- [ ] Cài đặt công cụ Joern (xét phiên bản phù hợp).
- [ ] Viết script Python tự động hóa việc gọi Joern CLI / CPG export sang định dạng JSON chuẩn.

### Giai đoạn 2: Lập trình lại Module Lựa chọn Ví dụ (Demonstration Retrieval)
- [ ] Xây dựng `retrieve_demos.py` bám sát bài báo.
- [ ] Tích hợp `CodeT5` tích xuất embedding và FAISS $L_2$ index.
- [ ] Bổ sung hàm tính Jaccard + SimSBT để re-rank top K ví dụ.

### Giai đoạn 3: Chuẩn hóa Script Đánh giá LLM
- [ ] Chuyển đổi toàn bộ hardcoded paths thành đường dẫn tương đối / CLI args.
- [ ] Tích hợp nạp OpenAI API Key qua file `.env`.
- [ ] Cấu trúc lại Prompt theo đúng Hình 6 của bài báo.
- [ ] Bổ sung cơ chế Retry & Checkpoint tiến độ.

### Giai đoạn 4: Chạy thử và Đối chiếu Thực nghiệm
- [ ] Chạy thử trên subset nhỏ (10-50 hàm).
- [ ] Đánh giá toàn bộ tập test và đối chiếu với F1-score trong bài báo (~65.11% trên Devign).
