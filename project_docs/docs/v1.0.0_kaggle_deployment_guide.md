# 🚀 Hướng Dẫn Triển Khai Thực Nghiệm GRACE Trên Kaggle GPU

Tài liệu này hướng dẫn chi tiết từng bước đưa bộ mã nguồn tái thiết kế GRACE lên môi trường máy chủ Kaggle GPU miễn phí và kích hoạt chạy thực nghiệm (Stage 5).

---

## 1. Cơ Chế Xử Lý & Tải Dữ Liệu (Data Loading Mechanism)

Hệ thống GRACE xử lý dữ liệu tự động 100% thông qua module `data_loader.py`:

```
+-----------------------------------+
|  Hugging Face Datasets Hub        |
|  (e.g., DetectVul/devign)         |
+-----------------+-----------------+
                  |
                  v (Hugging Face API `load_dataset`)
+-----------------+-----------------+
|  Standardization & Normalization  |
|  - func: Mã nguồn C/C++           |
|  - target: Nhãn 0 (Safe) / 1 (Vuln)|
|  - nodes & edges: Đồ thị Joern CPG|
+-----------------+-----------------+
                  |
                  v (Stratified Slicing via `scikit-learn`)
+-----------------+-----------------+
|  Sample Stratified Sub-dataset    |
|  (Ví dụ: 5% hoặc 10% tập dữ liệu)  |
+-----------------------------------+
```

### Chi Tiết Luồng Xử Lý:
1. **Nguồn Dữ Liệu**: Tải trực tiếp từ bộ dữ liệu uy tín trên **Hugging Face Hub** (ví dụ: `DetectVul/devign`, `SensorLLM/Reveal`).
2. **Chuẩn Hóa (Standardization)**: Tự động ánh xạ các trường dữ liệu đa dạng về cấu trúc thống nhất:
   - Mã nguồn hàm: `func`
   - Nhãn lỗ hổng: `target` (`0`: An toàn, `1`: Có lỗ hổng)
   - Thông tin đồ thị CPG/AST: `nodes` và `edges`
3. **Phân Tầng Cân Bằng (Stratified Slicing)**: Sử dụng `sklearn.model_selection.train_test_split` với `stratify=target` để trích xuất tập con (ví dụ 5% dataset) mà vẫn giữ nguyên tỷ lệ phân bố thực tế giữa hàm an toàn và hàm có lỗi.
4. **Cơ Chế Khôi Phục Chống Mất Mạng (Offline / Mock Fallback)**: Khi không có kết nối internet hoặc chạy dry-run cục bộ, hệ thống tự kích hoạt `generate_mock_dataset()` sinh dữ liệu mẫu để thử nghiệm tốc độ cao.

## 2. Quy Trình Triển Khai Trên Kaggle GPU (Step-by-Step)

### Bước 1: Tạo Notebook Mới Trên Kaggle
1. Đăng nhập vào [Kaggle.com](https://www.kaggle.com).
2. Bấm vào nút **Create** -> Chọn **New Notebook**.
3. Tại menu bên phải (**Notebook options**):
   - **Accelerator**: Chọn **GPU T4 x2** (hoặc GPU P100).
   - **Persistence**: Chọn **Variables and Files** (để giữ file nếu rerun).
   - **Internet**: Bật **On** (bắt buộc để tải dataset từ Hugging Face và tải trọng số LLM Open-Weights `Qwen2.5-Coder-7B-Instruct`).

### Bước 2: Tải Mã Nguồn Lên Kaggle
Có 2 cách đơn giản:

#### Cách A: Upload mã nguồn dưới dạng Kaggle Dataset (Đường dẫn hiện tại của bạn)
Đường dẫn đính kèm dataset của bạn: `/kaggle/input/datasets/huuhieu3333/grace-source-code` (hoặc `/kaggle/input/grace-source-code`). Vì thư mục `/kaggle/input` chỉ có quyền **Đọc (Read-Only)**, ta cần sao chép mã nguồn sang thư mục có quyền **Ghi (Writable)** `/kaggle/working/GRACE` tại Cell 0:

```python
# Cell 0: Sao chép mã nguồn sang /kaggle/working/GRACE
import os, shutil
src = '/kaggle/input/datasets/huuhieu3333/grace-source-code'
if not os.path.exists(src):
    src = '/kaggle/input/grace-source-code'

dest = '/kaggle/working/GRACE'
if os.path.exists(dest): shutil.rmtree(dest)
shutil.copytree(src, dest)
%cd /kaggle/working/GRACE
!ls -la
```

#### Cách B: Import trực tiếp file Notebook `GRACE_Kaggle_Reproduce.ipynb`
1. Trên giao diện Kaggle Notebook, chọn **File** -> **Import Notebook**.
2. Chọn tệp `GRACE_Kaggle_Reproduce.ipynb` có sẵn trong thư mục dự án.

## 4. Tự Động Phục Hồi Khi Bị Timeout (Resilience & Recovery)

Nếu Kaggle Notebook bị hết thời lượng session (Timeout sau 12h) hoặc bị ngắt giữa chừng:
1. Bạn chỉ cần **bấm chạy lại lệnh** `python run_pipeline.py ...` tương ứng.
2. Động cơ `CheckpointManager` sẽ tự động đọc file `checkpoints/checkpoint_<experiment_name>.jsonl`, nạp các mẫu đã đánh giá thành công và **tiếp tục đánh giá ngay lập tức tại mẫu dở dang** mà không tốn công chạy lại từ đầu!

## 5. Thu Thập Báo Cáo Nghiệm Thu
Sau khi hoàn tất, kết quả nghiệm thu sẽ nằm tại thư mục `/kaggle/working/output/`:
- `results_<experiment_name>.json`: Báo cáo trọn vẹn chi tiết từng prompt, lý giải suy luận của LLM và kết quả bóc tách.
- `summary_<experiment_name>.csv`: Bảng đối chiếu nhãn gán thực tế (Ground Truth) vs Nhãn AI dự đoán (Prediction).
