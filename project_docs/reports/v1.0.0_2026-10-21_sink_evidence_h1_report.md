# Kết quả triển khai H1 — bằng chứng sink tại lời gọi

Đã triển khai E1 trong `src/security_signature/sink_evidence.py` và script đo `scripts/run_sink_evidence_h1.py`. Production extractor, cách tính SecSim, guard, memory weights, retrieval và prompt không thay đổi. Không gọi LLM/API hay tải model.

## 1. Hành vi của E1

- Mask comment, string/char literal và preprocessor directive, giữ nguyên offset và newline của code gốc.
- Nhận diện call expression cân bằng ngoặc; loại function definition và prototype có prefix kiểu dữ liệu trong các ngữ cảnh lexical được hỗ trợ.
- Ghi API, family, start/end offset, dòng, nguyên biểu thức và nguồn bằng chứng. Giữ riêng từng call-site khi một API xuất hiện nhiều lần.
- Dùng 17 ánh xạ wrapper theo tên chính xác, ví dụ av_mallocz/g_free/bdrv_pread; không ánh xạ mọi hàm cùng prefix. Rule wrapper là giả thuyết phân loại thao tác cần audit, không phải tóm tắt whole-program đã được chứng minh.
- Helper/macro/member call chưa phân giải có status Unknown và lý do; không đổi Unknown thành Safe hoặc No-Sink.
- Không gán is_controlled, không tự kết luận guard đúng biến/đặt trước sink/có hiệu lực. Trả rõ guard_assessment=not_performed.
- API chỉ nhận code; không nhận target label, filename hoặc graph. Kiểm thử đổi metadata bên ngoài không làm đổi evidence.

E1 là scanner lexical bảo thủ, không phải C/C++ compiler. Chưa resolve type, shadowing, indirect call, macro expansion hay nhánh preprocessor hoạt động. Do đó chưa đưa E1 vào production.

## 2. Kiểm chứng trên fixture có đáp án tường minh

24 fixture được viết riêng để kiểm tra các failure mode: comment/string/variable giả API, declaration, definition, macro definition, call thật, call lồng nhau, repeated call, cast/return/conditional call, wrapper, helper/macro Unknown, member call và code bị cắt.

So E0 và E1 theo **tập API trên từng fixture** vì E0 không xuất call-site span:

| Chỉ số | E0 hiện tại | E1 thử nghiệm |
| --- | ---: | ---: |
| TP | 10 | 14 |
| FP | 12 | 0 |
| FN | 4 | 0 |
| Precision | 45.45% | 100% |
| Recall | 71.43% | 100% |

E1 còn được chấm riêng theo `(API, start, end)` exact call-site: 15 TP, 0 FP, 0 FN; **24/24 fixture khớp hoàn toàn**. Đơn vị này không được so trực tiếp với E0 chỉ xuất tập API.

Đây là bộ fixture phát triển có đáp án do người triển khai định nghĩa, không phải đánh giá độc lập hoặc bằng chứng accuracy 100% trên code thực tế.

## 3. Kiểm tra trên code thật

Đã cố định 50 mẫu còn lại của canonical dev-100, loại toàn bộ 50 mẫu review cũ, kèm opaque ID và hash code. Đây vẫn là dev set từng tham gia benchmark B2/B3, không phải final test chưa xem.

| Thống kê mô tả | Kết quả |
| --- | ---: |
| Mẫu có sink API ở E0 | 11/50 |
| Mẫu có sink API ở E1 | 14/50 |
| Mẫu có ít nhất một helper/macro/member Unknown ở E1 | 45/50 |

Các con số trên đo coverage, **không đo độ đúng**. Precision/recall trên code thật để null vì chưa có annotation call-site. Không dùng việc tăng từ 11 lên 14 để tuyên bố H1 đã thành công.

Đã tạo `sink_evidence_h1/verification_annotation_packet.json`: toàn bộ code và opaque ID, không kèm nhãn vulnerability, filename gốc, tên phương pháp hay prediction. `verification_manifest_private.json` lưu ánh xạ nguồn/hash riêng. Prediction E0/E1 nằm trong file riêng, không đưa vào packet annotation.

## 4. Kiểm thử và cách tái lập

Lệnh:

```powershell
python scripts/run_sink_evidence_h1.py
python -m pytest tests/test_sink_evidence.py tests/test_stage5_security_signature.py tests/test_stage5_synthetic_ground_truth.py -q
```

Kết quả: **44 tests pass** gồm 25 test E1 và các test signature/synthetic hiện có. Script ghi hash source E1, danh mục wrapper, manifest input, prediction, fixture output và summary để đối chiếu. Nếu danh sách hoặc code của 50 input bị thay đổi, lần chạy lại sẽ dừng thay vì ghi đè manifest đã cố định.

## 5. Trạng thái và bước kế tiếp

**Cập nhật cùng ngày:** Đã hoàn tất lượt annotation kỹ thuật và chấm 50 hàm, xem `v1.0.0_2026-10-21_sink_evidence_real_code_review_report.md`. Có 67 call-site trong phạm vi; E1 TP=33, FP=0, FN=34. Annotation này không độc lập với người triển khai, nên điều kiện xác nhận độc lập bên dưới vẫn chưa đạt. Các con số fixture/coverage phía trên là mốc ban đầu, không thay bằng metric code thật khác đơn vị.

Phần triển khai thử nghiệm và đo fixture đã hoàn tất. **Chưa đạt điều kiện chuyển H2:** cần annotation call-site trên code thật và audit semantic precision/recall, đặc biệt các wrapper và Unknown. Bộ annotation đã sẵn sàng; không giả lập đáp án con người để lấp phần còn thiếu.

Nếu evidence đạt yêu cầu mới chuẩn bị cùng top-50 CodeT5/full train pool cho R0/R1. Hiện không chạy lại retrieval bằng TF-IDF để thay thế CodeT5, không gọi LLM và không mở final test.
