## 3. Kế Hoạch Bước Tiếp Theo (Chuyển sang Giai đoạn 5: Cải Tiến Đột Phá)
1. **Security Chain-of-Thought (CoT) Prompting**: Khắc phục trực tiếp điểm nghẽn Recall thấp bằng cách yêu cầu LLM suy luận theo chuỗi *Source $\rightarrow$ Sink $\rightarrow$ Sanitization*.
2. **Contrastive In-Context Learning (2-shot tương phản)**: Cung cấp 1 cặp mẫu (1 Lỗ hổng + 1 An toàn) để mô hình so sánh đối chiếu ngữ nghĩa và đồ thị.
3. **Program Slicing / Subgraph Focus**: Lọc bỏ các node/edge không quan trọng, chỉ giữ lại lát cắt phụ thuộc dữ liệu/điều khiển liên quan đến các thao tác bộ nhớ nguy hiểm.
