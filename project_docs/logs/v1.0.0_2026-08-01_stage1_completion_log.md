# Nhật Ký Hoạt Động: Hoàn Thành Stage 1 (v1.0.0 - 2026-08-01)

## 1. Mục Đích Phiên Làm Việc (Session Goal)
Triển khai tầng cơ bản (Foundation Layer) cho dự án GRACE bao gồm module quản lý cấu hình tự nhận diện môi trường (`config.py`), bộ nạp & chuẩn hóa dữ liệu Hugging Face (`data_loader.py`), tính năng trích xuất 5% dữ liệu cân bằng nhãn (Stratified Slicing), và script kiểm thử nghiệm thu Stage 1.

## 2. Các Bước Thực Hiện & Kết Quả (Execution Steps)

### Bước 1: Xây dựng `config.py`
- Tự động phát hiện môi trường chạy (Local PC vs Kaggle Notebook `/kaggle/working`).
- Thiết lập đường dẫn động đến `data`, `checkpoints`, và `output`.
- Quản lý an toàn API Key qua biến môi trường hoặc `kaggle_secrets`.

### Bước 2: Xây dựng `data_loader.py`
- Tích hợp tải bộ dữ liệu lỗ hổng từ Hugging Face (`DetectVul/devign`, `bstee615/bigvul`).
- Hàm `standardize_sample()`: Chuẩn hóa mọi mẫu dữ liệu về schema thống nhất (`id`, `func`, `target`, `nodes`, `edges`).
- Hàm `slice_dataset()`: Cho phép trích xuất mẩu thử nghiệm 5% nhưng bảo toàn chính xác tỷ lệ nhãn (Stratified Sampling).
- Có cơ chế Fallback tự động sang Mock Dataset nếu không có internet hoặc khi chạy offline test.

### Bước 3: Nghiệm thu Milestone Checkpoint 1
- Tạo file kiểm thử `tests/test_stage1_loader.py`.
- Thực thi kiểm thử tự động:
  ```bash
  python tests/test_stage1_loader.py
  ```
- **Kết quả**: PASS 100% tất cả 4 test cases (`Config`, `Standardize`, `Stratified Slicing`, `HF Fallback`).
