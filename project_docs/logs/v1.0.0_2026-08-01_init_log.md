# Nhật Ký Hoạt Động: Khởi Tạo Cấu Trúc Thư Mục Quản Lý Dự Án (v1.0.0 - 2026-08-01)

## 1. Mục Đích Phiên Làm Việc (Session Goal)
Thiết lập thư mục quản lý dự án chuẩn hóa gồm 3 thư mục con: `plans`, `progress`, và `logs` cùng các quy chuẩn về đặt tên và định dạng file cho Con người và AI Agent dễ dàng theo dõi và cập nhật.

---

## 2. Chi Tiết Các Bước Thực Hiện (Execution Steps)

### Bước 1: Khởi tạo thư mục & Quy chuẩn tổng quan
- Tạo thư mục gốc `project_docs/` chứa `README.md`.
- File `README.md` định nghĩa quy tắc đặt tên (`vX.Y.Z_YYYY-MM-DD_...`), cú pháp YAML Frontmatter ở đầu file giúp AI đọc context nhanh và phân chia rõ mục tiêu cho con người.

### Bước 2: Tạo các file mẫu (Templates)
- `project_docs/plans/TEMPLATE_plan.md`: Mẫu lập kế hoạch phiên bản/tính năng mới.
- `project_docs/progress/TEMPLATE_progress.md`: Mẫu báo cáo tiến độ và danh sách công việc.
- `project_docs/logs/TEMPLATE_log.md`: Mẫu ghi nhật ký thực thi, sửa lỗi & nghiệm thu.

### Bước 3: Đưa dữ liệu hiện tại vào hệ thống v1.0.0
- Chuyển file `grace_analysis_plan.md` thành `project_docs/plans/v1.0.0_2026-08-01_grace_analysis_plan.md`.
- Chuẩn hóa kế hoạch tái cấu trúc & triển khai GRACE theo 5 Giai đoạn (Stage-by-Stage) từ `implementation_plan.md` vào `project_docs/plans/v1.0.0_2026-08-01_grace_implementation_plan.md`.
- **Đánh giá & chốt 2 câu hỏi mở**:
  1. *Dữ liệu*: Chốt dùng bộ preprocessed Joern CPG của chính Tác giả bài báo (Google Drive) để đảm bảo 100% tính chính xác F1-Score khi tái tạo.
  2. *Mô hình LLM*: Thiết lập kiến trúc Multi-Provider LLM Engine hỗ trợ 100% MIỄN PHÍ qua Kaggle Local GPU (`Qwen2.5-Coder-7B`) & Gemini 1.5 Flash Free API, bên cạnh tùy chọn DeepSeek/OpenAI API giá rẻ.
- Khởi tạo file theo dõi tiến độ: `project_docs/progress/v1.0.0_2026-08-01_project_progress.md`.
- Khởi tạo file nhật ký hoạt động đầu tiên: `project_docs/logs/v1.0.0_2026-08-01_init_log.md`.
