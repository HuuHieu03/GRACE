## 2. Các Thay Đổi & Thành Phần Đã Thực Hiện (Implementation Details)
- **`prompt_engine.py`**:
  - Tích hợp hàm `format_graph_structure` tóm tắt các nút/cạnh của CPG/AST thành văn bản trực quan.
  - Hàm `build_grace_prompt()` kết hợp trơn tru 4 phần: Task Instruction -> Demonstration Example (từ Stage 2) -> Target Query -> Output Formatting Constraint.
- **`metrics.py`**:
  - Xây dựng hệ thống tính toán chính xác True Positive (TP), False Positive (FP), True Negative (TN), False Negative (FN), từ đó xuất ra báo cáo `print_metrics_summary()` dưới dạng bảng biểu chuyên nghiệp.
- **`evaluator.py`**:
  - `parse_llm_prediction()`: Sử dụng hệ thống Regex 4 tầng (Exact binding -> JSON format -> Concluding heuristics -> Safe Fallback) chịu được hiện tượng lan man hoặc bọc markdown của LLM.
  - `CheckpointManager`: Ghi đĩa realtime theo dạng JSONL sau từng record. Nếu xảy ra timeout hoặc crash trên Kaggle, tự động đọc checkpoint cũ và nạp lại trạng thái mà không chạy lặp lại các mẫu đã qua.
  - `LLMEvaluator`: Điều phối chạy Open-Weights (`Qwen2.5-Coder-7B-Instruct`) trên GPU Kaggle hoặc chuyển động tự làm mới sang Intelligent Mock Generater để test tốc độ nhanh tại Local.
