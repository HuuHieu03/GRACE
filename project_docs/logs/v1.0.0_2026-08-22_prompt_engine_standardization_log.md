# Nhật Ký Chuẩn Hóa Prompt Engine Theo Chuẩn 100% Bài Báo GRACE (Figure 6)

## 1. Bối cảnh & Phát hiện
Sau khi nghiệm thu kết quả thực nghiệm Baseline trên 100% tập kiểm thử của 2 dataset **Devign** (2,732 mẫu) và **Reveal** (2,274 mẫu), quá trình rà soát chi tiết mã nguồn so với **Mục 3.3 & Hình 6 (Figure 6)** của bài báo khoa học GRACE cho thấy:
* **Paper GRACE (Mục 3.3 - Figure 6)**:
  * Phần **Demonstration (Ví dụ mẫu)** chỉ bao gồm: Mã nguồn C/C++ của ví dụ (`[demonstration]`) + Nhãn nhị phân (`[label]`: Vulnerable / Non-vulnerable). Tác giả KHÔNG đưa đồ thị CPG hay reasoning của mẫu ví dụ để tránh quá tải ngữ cảnh (Context Window limit ~8192 tokens của GPT-4).
  * Phần **Target Query (Hàm cần kiểm tra)**: Chứa toàn bộ mã nguồn (`[code snippet]`) + cấu trúc đồ thị CPG (`[node information]` & `[edge information]`).
* **Phiên bản cũ trong `prompt_engine.py`**:
  * Đã vô tình bổ sung thêm `DEMONSTRATION GRAPH STRUCTURE` (tóm tắt đồ thị cho mẫu ví dụ) và `Expert Reasoning` (chuỗi giải thích tổng quát giả định).
  * Việc này làm tăng độ dài prompt không cần thiết, làm loãng sự chú ý của mô hình vào hàm target và tạo ra thiên kiến suy luận giả.

## 2. Các thay đổi kỹ thuật chi tiết

### A. Tái cấu trúc `prompt_engine.py`
1. **Phần Nhiệm vụ & Định danh Chuyên gia ($P_i + P_d + P_b$)**:
   * Khớp chính xác với mô tả tại Mục 3.3:
     - $P_i$: *"You are now an excellent programmer."*
     - $P_d$: *"You are conducting a function vulnerability detection task for C/C++ language."*
     - $P_b$: *"In the above target code snippet, check for potential security vulnerabilities and output either '1' if Vulnerable or '0' if Non-vulnerable."*
2. **Phần Demonstration (1-shot ICL)**:
   * Loại bỏ hoàn toàn `demo_graph` và `demo_reasoning`.
   * Chỉ giữ lại:
     - Tiêu đề dẫn hướng: *"Here is an example for you to learn from:"*
     - Mã nguồn của hàm mẫu: `--- DEMONSTRATION CODE ---`
     - Nhãn kết luận: `--- DEMONSTRATION GROUND TRUTH LABEL --- Label: Vulnerable (1) / Non-vulnerable (0)`
3. **Phần Target Function & CPG Graph**:
   * Đưa danh sách Node (`format_node_information`) và Edge (`format_edge_information`) chuẩn hóa theo phong cách Figure 5/6:
     - `The node information of the function is as follows:` (Node ID, Node Type, Snippet Code)
     - `The edge information of the function is as follows:` (Node X -> EdgeType -> Node Y)
