# Conversation & Session History

Thư mục này dùng để lưu trữ các bản tóm tắt cuộc trò chuyện, lịch sử trao đổi quan trọng và các quyết định thiết kế giữa User và Agent khi thực hiện dự án GRACE.

## Quy tắc đặt tên file
- `YYYY-MM-DD_session_summary.md` (ví dụ: `2026-08-04_session_summary.md`)
- Hoặc theo mốc tính năng: `vX.Y.Z_YYYY-MM-DD_<topic>_summary.md`

## Nội dung đề xuất cho mỗi file tóm tắt
1. **Mục tiêu phiên làm việc**
2. **Các công việc đã thực hiện**
3. **Các quyết định / Thảo luận quan trọng**
4. **Trạng thái hiện tại & Bước tiếp theo**
